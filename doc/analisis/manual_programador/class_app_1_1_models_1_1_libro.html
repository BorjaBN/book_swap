Descripción detallada

Modelo Libro

Representa un libro registrado por un usuario dentro de la plataforma. Cada libro pertenece a un usuario común y puede participar en uno o varios intercambios, tanto como libro solicitado como libro ofrecido.

Este modelo no solo almacena datos, sino que encapsula comportamiento propio del dominio del libro dentro del sistema.
