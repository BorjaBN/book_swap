Descripción detallada

Modelo UsuarioComun

Representa a un usuario estándar dentro de la plataforma. Este modelo extiende de Authenticatable para permitir autenticación propia, utilizando su tabla y credenciales específicas.

Este modelo encapsula el comportamiento natural del usuario dentro del sistema, manteniendo la lógica de dominio cohesionada y evitando controladores inflados.
