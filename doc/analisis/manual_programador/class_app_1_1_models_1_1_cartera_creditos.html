Descripción detallada

Modelo CarteraCreditos

Representa la cartera de créditos asociada a un usuario común. Cada cartera almacena el saldo total del usuario y mantiene un historial de movimientos (cargos, abonos, devoluciones, etc.).

Relaciones principales:

  • Una cartera pertenece a un usuario común.
  • Una cartera tiene muchos movimientos de crédito.
