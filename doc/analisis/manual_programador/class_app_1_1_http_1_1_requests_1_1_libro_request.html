Descripción detallada

Form Request para validar la creación y edición de libros.

Detecta automáticamente si la petición corresponde a un alta o a una edición comprobando si existe un modelo Libro en la ruta. En función de ello, aplica reglas más estrictas (required) o más flexibles (nullable), especialmente para la imagen y el ISBN.
