## Edición de datos del libro

Como usuario común<br>
quiero editar los datos de un libro<br>
para corregir información y mantenerla correcta.

Criterios de aceptación:

    Usuario autenticado como usuario común puede acceder a la edición de sus libros publicados desde la ficha de detalles del libro.

    Se muestran los datos actuales del libro (título, autor, ISBN, estado, genero (opcional), fecha de publicación y foto).

    El usuario puede modificar todos los campos.

    Los cambios se validan antes de guardar y, en caso de error, se muestra en el formulario impidiendo que se guarden los cambios.

    Si no hay ningún error, la información se actualiza correctamente mostrando la ficha de detalle del libro.

    El usuario puede cancelar la edición sin guardar cambios.
