## Consulta de libros propios publicados

Como usuario común<br>
quiero ver la lista de mis libros publicados<br>
para gestionar mis publicaciones y saber cuáles están disponibles.

Criterios de aceptación:

    Un usuario autenticado como usuario común puede acceder a su listado de libros publicados en la sección "Mis libros" de la página "Perfil".

    Se muestra una tarjeta de cada libro con información básica: título, autor, imagen, propietario. Además hay un botón de "Más detalles" para acceder a la ficha del libro.

    Si no hay libros publicados, el sistema indica que la lista está vacía.

    La lista permite ordenar o filtrar por fecha.
