# Eliminación del perfil 

Como usuario <br>
quiero eliminar mi cuenta <br> 
para eliminar mi información de la plataforma de forma segura.

Criterios de aceptación: 

    El usuario autenticado puede acceder a la opción de "Eliminar perfil" desde su perfil.

    El sistema solicita confirmación antes de eliminar el perfil.

    Al confirmar, el perfil y los datos asociados se eliminan correctamente.

    El sistema muestra un mensaje de éxito después de la eliminación y redirige a la ventana de bienvenida.

    Si el usuario cancela, no se elimina ninguna información.
