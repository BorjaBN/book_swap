## Rechazo de solicitud de intercambio

Como usuario común<br>
quiero aceptar una solicitud de intercambio recibida<br>
para confirmar el intercambio de un libro con otro usuario común

Criterios de aceptación:

    Un usuario autenticado como usuario común puede ver las solicitudes de intercambio recibidas en la sección "Solicitudes" de la página "Perfil".

    El usuario puede aceptar una solicitud pendiente.

    Al aceptar, el sistema actualiza el estado del intercambio a “aceptado”.

    Se notifica al usuario solicitante sobre la aceptación.

    El sistema ajusta créditos o registros asociados si aplica.
