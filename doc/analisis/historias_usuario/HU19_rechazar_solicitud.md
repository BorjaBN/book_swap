## Rechazo de solicitud de intercambio

Como usuario común<br>
quiero aceptar una solicitud de intercambio recibida<br>
para confirmar el intercambio de un libro con otro usuario común

Criterios de aceptación:

    Un usuario autenticado como usuario común puede rechazar las solicitudes de intercambio de las propuestas de intercambio que menos desee desde la sección "Solicitudes" situada en menú de navegación inferior.

    El sistema notifica al propietario del libro sobre la solicitud.

    Al rechazar, el sistema actualiza el estado del intercambio a “rechazado”. Esto se puede ver en la sección de "Solicitudes" situada en menú de navegación inferior.

    El sistema devuelve créditos al usuario que realizó la solicitud.
