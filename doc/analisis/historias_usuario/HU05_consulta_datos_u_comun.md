## Consulta de datos de usuario común

Como usuario común<br>
quiero consultar mi perfil<br>
para ver y gestionar mi información personal.

Criterios de aceptación:

    El usuario autenticado puede acceder a su perfil.

    El sistema muestra la información personal registrada (nombre, apellidos, correo electrónico, telefono y ciudad).

    La información se presenta de forma clara y legible.
