## Consulta del catálogo completo

Como usuario común<br>
quiero ver el catálogo completo de libros disponibles<br>
para explorar todas las opciones de intercambio.

Criterios de aceptación:

    El sistema muestra todos los libros disponibles para intercambio en la página "Libros".

    Se muestra una tarjeta de cada libro con información básica: título, autor, imagen, propietario. Además hay un botón de "Más detalles" para acceder a la ficha del libro.

    La lista se puede navegar fácilmente (paginación).

    Si no hay libros, se indica que el catálogo está vacío.
