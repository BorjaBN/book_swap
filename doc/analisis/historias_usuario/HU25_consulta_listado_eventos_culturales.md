## Consulta de listado de eventos culturales

Como usuario común<br>
quiero consultar el listado de eventos culturales<br>
para conocer las actividades disponibles.

Criterios de aceptación:

    El sistema muestra todos los eventos publicados en la página "Eventos".

    Se muestra una tarjeta de cada evento con información básica: nombre, fecha, descripción, ubicación y tipo.

    La lista se puede navegar fácilmente (scroll infinito).

    Si no hay eventos, se indica que el listado está vacío.
