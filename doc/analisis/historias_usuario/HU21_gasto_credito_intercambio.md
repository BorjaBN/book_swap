## Gasto de créditos al intercambiar

Como usuario<br>
quiero gastar créditos al realizar un intercambio<br>
para obtener libros de otros usuarios o entidades.

Criterios de aceptación:

    El sistema descuenta créditos al solicitar un intercambio.

    Se valida que el usuario tenga créditos suficientes.

    El saldo se actualiza correctamente tras el gasto.

    Si no hay créditos suficientes, se impide la solicitud de intercambio.

    Si la solicitud se rechaza, los créditos se vuelven a sumar en la cartera.
