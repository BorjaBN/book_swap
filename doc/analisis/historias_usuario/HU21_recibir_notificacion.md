## Recepción de notificación

Como usuario común<br>
quiero recibir una notificación<br>
para estar informado en las novedades de mis intercambios.

Criterios de aceptación:

    Un usuario autenticado como usuario común puede recibir notificaciones de las solicitudes de intercambio.
    
    Las notificaciones son visibles desde la sección "Solicitudes" situada en menú de navegación inferior.

    El sistema notifica al usuario sobre sus solicitudes recibidas y enviadas con un número.

    Cuando se entra en "Solicitudes" desaparece el número que cuantifica las notificaciones, si no se interactúa, no desaparece.
