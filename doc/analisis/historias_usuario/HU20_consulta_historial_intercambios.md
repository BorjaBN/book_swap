## Consulta de distorial de intercambios

Como usuario común<br>
quiero consultar mi historico de solicitudes de intercambio<br>
para tener un registro de mis intercambios.

Criterios de aceptación:

    Un usuario autenticado como usuario común puede ver las solicitudes de intercambio aceptadas, rechazadas o pendientes.
    
    El historico visible desde la sección "Solicitudes" situada en menú de navegación inferior.

    Las solicitudes se mantienen registradas en dicha sección.

    Cuando se entra en "Solicitudes" desaparece el número que cuantifica las notificaciones, si no se interactúa, no desaparece.
