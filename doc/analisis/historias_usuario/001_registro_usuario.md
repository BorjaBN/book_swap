# HISTORIAS DE USUARIO: REGISTRO DE USUARIO (USUARIO COMUN / ENTIDAD CULTURAL)

Como usuario no registrado aún,<br>
quiero registrarme en la plataforma bien como usuario o entidad cultural,<br>
para acceder a BookSwap.

Criterios de aceptación:

➔ El visitante accede a la opción "***Registrarse***" desde la página principal

➔ Le lleva a otra página donde puede elegir cómo quiere registrarse

➔ Debe completar el formulario con  los datos: nombre, apellidos (solo en opción de usuario comun), correo electrónico, contraseña, teléfono y ciudad 

➔ Se valida que el correo no esté ya registrado y que se rellenen el resto de campos obligatorios

➔ Al registrarse, se muestra un mensaje de confirmación y se inicia sesión automáticamente
