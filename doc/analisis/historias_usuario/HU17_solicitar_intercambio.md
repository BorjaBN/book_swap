## Envío de solicitudes de intercambios

Como usuario común<br>
quiero enviar solicitudes de intercambio de libros<br>
para proponer un intercambio con otro usuario común

Criterios de aceptación:

    Un usuario autenticado como usuario común puede seleccionar un libro de interés y enviar solicitud desde la ficha del libro.

    El sistema redirige a un formulario, donde se debe de seleccionar el libro que se desea intercambiar por el libro solicitado, después de seleccionarlo se pulsa el botón de "Enviar Solicitud".

    El sistema notifica al propietario del libro sobre la solicitud.

    Se guarda el estado de la solicitud (pendiente). Esto se puede ver en la sección de "Solicitudes" en la barra de navegación.

    Al solicitar el intercambio se restan  los créditos de la cartera de créditos asociada al usuario.

    Si no tiene créditos suficientes se notifica al usuario que no es posible realizar el intercambio.
