## Consulta de datos de entidad cultural

Como entidad cultural<br>
quiero consultar mi perfil<br>
para ver y gestionar mi información institucional.

Criterios de aceptación:

    El usuario autenticado puede acceder a su perfil.

    El sistema muestra la información personal registrada (nombre, NIF, telefono, sitio web (opcional), correo electrónico, dirección y ciudad).

    La información se presenta de forma clara y legible.
