## Consulta de movimiento de créditos

Como usuario común<br>
quiero consultar el historial de movimientos de créditos<br>
para revisar ingresos y gastos realizados.

Criterios de aceptación:

    Un usuario autenticado como usuario común puede acceder al historial de movimientos desde la sección "Mis movimientos" en la página "Perfil".

    Cada movimiento muestra fecha, descripción y cantidad.

    El historial se presenta ordenado cronológicamente.

    Si no hay movimientos, se indica correctamente.
