# HISTORIAS DE USUARIO 


Estas son las historias de usuario de éste nuestro proyecto:


---
Como usuario no registrado aún,<br>
quiero registrarme en la plataforma bien como usuario o entidad cultural,<br>
para acceder a BookSwap.

Criterios de aceptación:

➔ El visitante accede a la opción "***Registrarse***" desde la página principal.

➔ Le lleva a otra apgina donde puede elegir como quiere registrarse.

➔ Puede completar el formulario con datos:nombre, apellidos, correo electrónico, contraseña, teléfono y ciudad (Siendo todos los campos obligatorios).

➔ Se valida que el correo no esté ya registrado y que se rellenen el resto de campos obligatorios.

➔ Al registrarse, se meustra un mensaje de confirmación y se inicia sesión automáticamente.

---

Como usuario ya registrado,<br>
quiero iniciar sesión en la plataforma, <br>
para acceder a BookSwap.

Criterios de aceptación:

➔ El usuario accede a la opción "***Iniciar sesión***" desde la página principal.

➔ Puede introducir su correo electrónico y contraseña (ambos obligatorios).

➔ Se valida que el correo esté registrado y que la contraseña coincida.

➔ Si los datos son correctos, se muestra un mensaje de bienvenida y se inicia sesión.

➔ Si los datos son incorrectos, se muestra un mensaje de error indicando el problema.

---

Como usuario ya registrado,<br>
quiero consultar mis datos personales en la plataforma, <br>
para verificar mi información en BookSwap.

Criterios de aceptación:

➔ El usuario accede a la opción "***Mi perfil***" desde el menú principal.

➔ Se muestran los datos registrados.

➔ Se muestran también los botones de "***Eliminar cuenta***" y "***Editar Perfil***".
