## Registro de entidad cultural

Como entidad cultural<br>
quiero registrarme en la plataforma<br>
para poder publicitar mis eventos en la aplicación.

Criterios de aceptación:

    El usuario proporciona sus datos administrativos básicos: nombre, NIF, telefono, sitio web (opcional), correo electrónico, contraseña, dirección y ciudad.
    
    El sistema debe permitir el registro solo si todos los campos obligatorios están completos y son válidos.

    El correo electrónico y el NIF no deben existir previamente en la base de datos.

    Si el registro es exitoso, el sistema debe crear la cuenta y redirigir al inicio.

    Si hay errores (campos que no cumplen las validaciones, correo electrónico duplicado), el sistema debe mostrar mensajes claros indicando el problema.
