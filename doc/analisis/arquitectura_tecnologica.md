# Aquitectura tecnológica

Este documento describe la arquitectura tecnológica utilizada en el desarrollo de BookSwap. Se detalla el stack completo de tecnologías empleadas con su versión.

### Entorno de desarrollo

- **Sistema operativo:** Windows 11 Home 25H2  
- **Servidor local:** XAMPP (Apache + MariaDB)  
- **Editor de código:** Visual Studio Code  
- **Control de versiones:** Git + GitHub  
- **Base de datos:** `bookswap` con tablas normalizadas según el modelo entidad-relación definido en el análisis del sistema
- **Navegador de pruebas:** Google Chrome 142.0.7444.163 con motor V8 14.2.231.18
